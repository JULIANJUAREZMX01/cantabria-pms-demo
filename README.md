# Hotel Cantabria — PMS Multihotel & Concierge IA (Demo Beta)

Plataforma de gestión para el piloto del Hotel Cantabria (Tulancingo de Bravo, Hgo.)

## Módulos
- Limpieza Rápida (táctil, sin fricción para el personal)
- Panel Recepción / PMS (estancias, tarifas, extras)
- Concierge & Extras Eco (upselling: agua alcalina, kits de bambú, café orgánico)
- Arquitectura KynicOS (conexión Telegram/WhatsApp con backend Base44)
- Vista Web Pública (reserva directa, ES/EN)

## Demo en vivo
https://julianjuarezmx01.github.io/cantabria-pms-demo/

## Stack
React 18 + Tailwind (CDN) — single-page build, sin backend en la demo.
Backend operativo real (entidades vivas + concierge IA): KynicOS @ Base44.
